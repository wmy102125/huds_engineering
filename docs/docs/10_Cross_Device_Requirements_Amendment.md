# v1.2 跨设备功能要求（P0）
- Desktop Chrome/Edge、macOS Safari 与 Android Chrome、iOS Safari：均可独立执行维修完整闭环；具体最低浏览器版本 Sprint 0 冻结。
- Desktop：快捷键、筛选/排序、主从多栏、键盘输入、打印；Mobile：触控、拍照、单列逐步流程、断网提醒。
- 共用同一 REST API、权限、服务端状态机、证据规则；不能为两个端建立两套主数据。
- 电脑端也应在支持 IndexedDB 的浏览器具备受控离线新增能力；任何浏览器清理缓存/隐私模式可能丢失本地未同步数据，需提示和备份策略。
- 同一 Case 多设备并发：测量事实 append-only + 幂等键；客户/设备可编辑字段 If-Match/row_version；状态转换服务端权威，409/412 冲突显式人工处理；不得静默 LWW。
- 验收：电脑创建案件→手机离线诊断→恢复同步→电脑查看完整证据；反向从手机创建→电脑诊断也应成立。
