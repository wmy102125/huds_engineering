|---|---|---|---|
| AT-01 | 断网创建案件 | 断网新建设备、Case、Visit、假设、测量 | 本地持久化，UI 标识待同步 |

| AT-06 | 停工 | 危害不可控，标 STOP_WORK | 禁止相关测试与维修 |
| AT-07 | 非数值测量 | reading_kind=OL，actual_value=null | 合法保存；NUMERIC/null 拒绝 |
| AT-08 | 证据更正 | 修改历史测量 | 仅新增 amendment，原证据保留 |
| AT-09 | DOA 配件 | IN_REPAIR 中记录 DOA | 转 PENDING_PARTS，记录原因 |
| AT-10 | 推翻假设 | 维修失败 | 返回 DIAGNOSING，保留历史 |
| AT-11 | 验证失败 | VERIFYING 中 FAIL | 不得 FIXED_VERIFIED 结案 |

| AT-13 | 离线签名冲突 | 旧报价离线签名，新报价已发布 | 需冲突审查，不能自动批准 |
| AT-14 | 一案多次上门 | 访问 2 次 | 两条 Visit、独立安全评估 |
| AT-15 | 历史地址 | 设备搬家后查旧 Case | 保留旧服务地址快照 |
| AT-16 | 媒体续传 | 上传中断、重复 finalize | 校验 SHA-256，不重复挂载 |
| AT-17 | 知识反证 | 提交相反案例 | 规则证据明确 CONTRADICTS |
| AT-18 | 权限 | 技师尝试读无权限客户 | 403，不泄露个人信息 |
| AT-19 | 浏览器存储丢失 | 清除未同步 IndexedDB | 明确告警及风险文档，不能承诺自动恢复 |
| AT-20 | 备份恢复 | 恢复数据库+媒体清单 | 引用完整，审计与授权仍可查 |
